隐私政策

适用版本：云序文件批量改名工具 0.2.23　·　更新日期：2026 年 9 月 9 日

云序文件批量改名工具是一款 Windows 本地文件批量改名软件。软件以完成用户主动发起的文件整理任务所必需的最少数据处理方式运行。

一、软件会访问和处理哪些数据

当用户主动选择文件、文件夹或 Excel 映射表时，软件会在本机访问和读取完成改名任务所需的信息，包括：

  • 用户主动选择的文件名、文件路径和文件系统属性；
  • Excel 映射表中由用户指定用于匹配或组成新文件名的内容；
  • 用户选择使用的照片、音频、视频等文件元数据；
  • 用户设置的命名规则、文件属性模板和界面设置。

这些信息仅用于在用户设备上生成名称预览、检查目标名称、执行用户确认的文件操作、生成本地报告，以及在需要时实现失败恢复或撤销。开发者不会通过本软件接收这些待处理内容。

二、联网与数据上传

软件离线运行，不主动连接云服务，不主动上传待处理文件或上述用户数据。软件不要求注册账户，也不内置广告、云同步或遥测上传功能。

当用户主动点击“联系作者”的电子邮件入口时，Windows 可能调用设备上已配置的邮件应用。用户随后主动发送的邮件内容，由相应邮件服务提供方按照其隐私政策处理。

三、本地保存的数据

Microsoft Store 版本会在当前 Windows 用户的本地应用数据目录中保存运行所需的数据，当前路径设计为：

%LOCALAPPDATA%\云序项目\云序文件批量改名工具

其中可能包含：

  • settings.ini：界面设置，以及一个最近使用的文件/目录选择位置；
  • logs：本地运行日志；
  • reports：本地 CSV 报告；
  • temp：Excel 等数据的临时解析文件；
  • transactions：原位置改名的事务、恢复和撤销记录；
  • rule-presets：用户主动保存的命名规则方案；
  • property-presets：用户主动保存的文件属性模板方案。

日志和报告可能包含文件名、本地路径、处理结果和错误信息，仅保存在本机。软件默认清理 30 天前的日志和报告。

四、数据共享、出售与第三方提供

本软件不会主动把待处理文件、文件名、文件路径、Excel 内容、媒体元数据、日志或报告提供、出售或共享给第三方。

五、用户控制与删除

用户可以通过软件中的数据管理入口清理本地日志和报告。不再使用软件时，可以卸载应用，并按 Windows 提供的应用数据管理方式清除本地数据。仍需用于恢复或撤销的事务记录，应在确认不再需要后再清理。

六、儿童隐私

本软件不是专门面向儿童设计的在线服务，不建立用户账户，也不主动收集儿童个人信息。若用户使用本软件处理包含未成年人信息的本地文件，相关文件仍由用户自行管理并保留在用户设备上。

七、本隐私政策网页的托管

本隐私政策网页托管在 GitHub Pages。访问此网页时，GitHub 可能为了站点安全等目的处理访问日志信息。相关处理由 GitHub 按其隐私政策负责；这与“云序文件批量改名工具”本身的本地文件处理相互独立。

八、政策更新

如果未来版本增加联网、账户、云同步、遥测或其他会改变数据处理方式的功能，我们会在相关功能上线前更新本隐私政策，并更新本页的日期。
